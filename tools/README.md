# Still renderer

The cinematic images in `assets/stills/` are rendered with Python (numpy + Pillow), not photographs.
Run `python3 render_scenes_1.py lighthouse lowtide desert_camera` or
`python3 render_scenes_2.py forest fogmount raincity neon portrait_warm` from this folder; output goes to `out/`.
Replace the files in `assets/stills/` with real photography whenever it's available; names must stay the same.
